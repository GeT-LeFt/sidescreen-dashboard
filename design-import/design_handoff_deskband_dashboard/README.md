# Handoff: 3840×1100 触摸带鱼副屏仪表盘

## Overview

一块 3840×1100 像素的超宽横向触摸副屏(物理 35cm × 11cm,约 278 PPI,挂在主显示器下方,观距约 60cm),作为 PC 的常驻信息仪表盘 + 触摸操控台。深色科技风,中文界面,固定分辨率不需要响应式。

产品形态:**3 个可上下滑动切换的一级页面 + 1 个自动进出的游戏副驾驶页**,深层内容一律用统一弹层母版承载。

## About the Design Files

本包中的 `.dc.html` 文件是**用 HTML 制作的设计参考稿(design reference)**,展示目标外观与交互行为,**不是可直接上生产的代码**。任务是在目标代码库的既有环境(如 Electron + React、Tauri、Qt、WPF 等)中**重新实现**这些设计;若尚无既有环境,请为"Windows 桌面副屏应用 + 硬件监控 + 系统音频控制"这一场景选择最合适的技术栈(推荐 Electron/Tauri + Web 前端,便于复刻本设计的 CSS)。

打开方式:直接用浏览器打开 `.dc.html` 文件即可预览(需与 `support.js` 同目录,联网加载字体和封面图)。

## Fidelity

**High-fidelity(高保真)**。颜色、字号、间距、圆角、布局均为定稿值,应按像素级复刻。交互原型中的手势、按压反馈、弹层行为也是定稿交互,应照实现。假数据(GPU 62%、歌曲《夜航星图》等)仅为演示,需接真实数据源。

两份文件:
- `Dashboard 交互原型.dc.html` — **主交付物**。可交互:切页、弹层、拖动滑块、长按等均可操作,是行为的权威参考。
- `Dashboard v2 触摸版(静态定稿).dc.html` — 全部页面/弹层平铺展示的静态稿(带 1a/2a…编号),便于一屏看全和对照标注。

两者如有出入,以交互原型为准。

## 信息架构(一级页面,按使用模式分类)

页面纵向堆叠,上下滑动切换;顺序:①看板 → ②操控台 → ③沉浸媒体。游戏副驾驶不在滑动序列中(自动进出,亦有手动入口)。

### ① 看板(瞟) — 只读监控
- 左~35%:性能磁贴网格 5×2(GPU 利用率+温度 / CPU 利用率+频率 / 内存 / 显存 / GPU 功耗 / GPU 风扇 / 磁盘读写 / 网络延迟 / 进程数 / 开机时长)。每贴:顶部标题+型号小字、大数字主指标(等宽字体)、下方副指标、**底部通铺半透明面积折线图**(SVG,绝对定位压底边,不占布局)。
- 中~30%:超大时钟(时:分 260px + 秒小号强调色)+ 星期/日期/农历;下半 Claude Code 用量面板(大环形=会话额度 68%、两条横向条=周额度 42%/Opus 61%、重置倒计时、OAuth 令牌过期倒计时——临期变橙/红),角落 80×80 像素风吉祥物。
- 右前~20%:正在播放卡(封面+歌名/歌手+进度)+滚动歌词(当前句高亮放大)+天气横条(当前温度/图标/高低温/未来3小时)。
- 最右~15%:今日日程(≤5条)、手机通知流(≤4条,应用图标+标题+摘要)、服务器健康小卡(状态点+延迟+uptime)。
- 点任意性能磁贴 → 弹出磁贴详情弹层(大曲线+时间范围切换+多指标)。

### ② 操控台(戳) — 触摸操作
三行分组网格布局:
- **应用启动**:Edge、VS Code、Steam、微信、网易云、文件管理器等彩色圆角方块图标。**Steam 特殊:短按直接打开 Steam;长按 1.5s 弹出 Steam 弹层**(内含:启动大屏模式、商店、游戏库、好友、最近游戏 3×2、下载状态)。另有"游戏副驾驶"手动入口按钮。
- **声音磁贴**:内嵌主音量滑条+静音钮(点控件直接调节);**点磁贴空白处 → 弹出声音控制弹层**。
- **系统开关**:网络、蓝牙、实时字幕(Win11 自带字幕)开关;锁屏/睡眠/重启/关机(**危险操作一律长按 1.5s 触发**)。

### ③ 沉浸媒体(听歌模式)
左:460×460 大封面+歌名/歌手/专辑;中:大字滚动歌词;右:播放队列(封面缩略+曲名+时长,当前曲高亮)。

### ④ 游戏副驾驶(自动进出)
检测到游戏进程/全屏 → 自动切入并**禁用切页手势**;退出游戏自动返回。内容:游戏名+FPS 大数字+帧生成时间曲线、GPU/CPU/温度精简磁贴、麦克风/扬声器快捷静音、Discord 语音状态、时钟。演示原型里用 Tweaks 的 `simulateGame` 布尔量模拟进出。

## 底栏(每页专属,高 170px,左侧=当前页名)

- 看板页:截图 / 麦克风静音 / 勿扰 / 防息屏 / 便签 / 番茄钟 + **音量条 + 亮度条**(可直接拖)
- 操控台页:网络 / 蓝牙 / 实时字幕 + 锁屏 / 睡眠 / 重启 / 关机(长按)
- 媒体页:播放/暂停/上一首/下一首 + 可拖进度条 + 音量 + 输出设备切换

## Interactions & Behavior

- **切页手势**:仅屏幕**左右边缘各 64px 热区**内的**上下拖动**有效(页面纵向堆叠);拖动跟手,阈值 180px(不足回弹),过渡 `transform 0.45s cubic-bezier(0.22,1,0.36,1)`。热区平时**不可见**,手指按入才浮现白色圆角把手+微光;首次开机闪一次提示。主体区域的滑动全部归控件(滑块/列表)所有,防误触。
- **按压反馈**(全部可点元素):`filter:brightness(0.75) + transform:scale(0.96)`,即手机风"变暗+微缩"。
- **长按**:危险操作(锁屏/睡眠/重启/关机)与 Steam 图标长按 = 按住 1.5s,有环形进度动画反馈,松手未满则取消。
- **弹层母版**:统一 3560×980 居中,背景遮罩 rgba(0,0,0,0.6),点弹层外空白关闭。所有深层内容(磁贴详情、声音控制、Steam 面板)共用此母版,不新增一级页面。
- **声音弹层**:左侧=全局输出设备大卡(耳机/音箱/显示器,点选切换)+主音量大滑条;右侧=**分应用混音台**,每应用一列:图标、垂直推子(上下拖)、静音钮、**输出设备块(点按轮换 默认→耳机→音箱→显示器)**。
- **磁贴详情弹层**:大面积历史曲线+时间范围切换(10分钟/1小时/24小时)+相关多指标小卡。
- **媒体**:进度条可拖 seek;切歌有淡入;歌词随播放滚动,当前句放大高亮。
- Toast:操作确认用短暂浮层提示(底部居中,深底白字)。

## State Management(接真实数据的建议)

原型中所有数据为假数据,实现时需接:
- **硬件监控**:LibreHardwareMonitor(开源,.NET,有 WMI/HTTP 接口)或 HWiNFO 共享内存 → GPU/CPU/内存/显存/功耗/风扇/磁盘/网络;1s 轮询,保留 24h 历史(环形缓冲)供详情曲线。
- **媒体**:Windows SMTC(`GlobalSystemMediaTransportControlsSessionManager`)读正在播放/控制播放;歌词需对接播放器(网易云等)或歌词 API。
- **音频**:Core Audio API — 主音量 `IAudioEndpointVolume`;分应用 `IAudioSessionManager2`;分应用输出路由用 AudioPolicyConfig(即系统"应用音量和设备首选项"能力)。
- **游戏检测**:进程监视(已知游戏进程名单)或前台全屏独占检测;FPS 需 PresentMon 或 RTSS 共享内存。
- **Claude Code 用量**:读本机 OAuth 凭据与用量接口,倒计时本地计算。
- **天气**:任意天气 API;**日程**:系统日历/CalDAV;**手机通知**:Phone Link 或 KDE Connect。
- **Steam**:`steam://` 协议启动(大屏模式 `steam://open/bigpicture`)+ Steam Web API 取库/好友/下载状态。
- 页面状态:当前页 index、弹层栈、各滑块值;设置(强调色、圆角)持久化本地。

## Design Tokens

颜色(深色科技风,近纯黑):
- 背景 `#0a0c10`;卡片 `#11151d`;卡片次级/内嵌块 `#171d27`、`#1a212c`;描边 `#1c222d`、次级 `#232b38`、`#2a3342`
- 文字:主 `#F2F6FA`/`#E7ECF2`,次 `#B9C3CF`/`#9AA6B5`/`#8A96A6`,弱 `#718092`,最弱/标签 `#525E6E`
- **强调色 CSS 变量 `--accent`,当前定稿橙色 `#F59E0B`**(备选:青 #22D3EE、绿 #34D399、紫 #A78BFA;全局仅此一个强调色,换肤=换变量)
- 语义:正常/在线 `#34D399`,警告 `#F59E0B`,危险/离线 `#F87171`
- 圆角 CSS 变量 `--radius`,定稿 **24px**(磁贴);弹层 28px;小控件 12–16px
- 卡片间距 16–22px;画布内边距 28px

字体:
- 中文/UI:**Noto Sans SC**(400/500/700/900)
- 数字/等宽:**JetBrains Mono**(500/700/800),所有数字加 `font-variant-numeric:tabular-nums`
- 大字标尺(278 PPI、观距 60cm 定稿):正文 ≥36px,辅助信息 ≥26px,磁贴主数字 ≥88px,时钟 260px;**触摸目标 ≥88px(物理约 8mm)**

图标:一律**线性描边 SVG(stroke 2px、圆头圆角)**,不用 emoji;应用图标=彩色圆角方块+单字/字母(实现时换真实应用图标)。
