# 公开发布边界

本次发布将个人 `config.json` 移出跟踪，并提供 `config.example.json`。运行中的安装目录与发布工作区分离；不会为了生成介绍页而替换用户配置或重启副屏。

## 图片

`docs/images/cover.svg` 是代码绘制的界面示意。四个 PNG 来自实际运行页面，但在浏览器请求阶段以 `tools/showcase-data.cjs` 的虚构数据替代会话、额度、媒体、日历、通知、音频与应用配置响应。敏感接口不返回真实内容，因此不需要把展示区域留空。图片包含 DEMO 标注；示例额度不代表实际账号用量。图中保留了本机性能指标和布局，它们不代表固定产品参数。

更新截图可以使用 `tools/capture-showcase.cjs`（需单独安装 Playwright 和 Edge）；脚本拒绝所有非 GET/HEAD 请求。示例数据仅供截图脚本使用，不参与实际运行。界面发生变化时，必须重新检查数据接口并人工审阅全部图片，不能只因为旧脚本运行成功就认定新截图安全。

## 禁止提交

- 本机配置、设备序列号、私有主机地址、日历 URL。
- 凭据、令牌、`.env`、私钥、认证文件。
- 会话记录、最后回复、额度历史、日志及未经脱敏的截图。
- 工作区备份、个人设计导出压缩包。

公开示例不得包含真实会话内容。仓库保留的本机回环地址用于本地服务通信，不是远程服务凭据。
